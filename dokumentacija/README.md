# Dokumentacija projekta EventRadar

Za mejnik Načrtovanje in prototipna dokumentacija ohranjava že pripravljeno zasnovo in jo dopolnjujeva z organizacijo dela ter začetnim CI.

## Obstoječa zasnova

[Prototipna dokumentacija](EventRadar_Prototipna_Dokumentacija.docx) vsebuje opis projekta, funkcionalnosti, ključne uporabniške scenarije, mockup petih zaslonov, navigacijo, začetni podatkovni model, arhitekturo, tehnologije, razvojne faze in tveganja. Dokument vsebinsko ohranjava.

![Obstoječi konceptni mockup aplikacije EventRadar](mockupi/koncept.png)

Mockup je izvoz slike iz obstoječega Wordovega dokumenta. Dogodki in datumi so ilustrativni. Novo različico zaslonov bova pripravila šele ob nadaljnjem razvoju.
