# Uvoz dogodkov

V tej mapi bova razvila uvoznik Python za dovoljene vire dogodkov. Jan Vid prevzame adapter prvega vira, normalizacijo datumov in prizorišč, preverjanje podvojitev ter zapis v Supabase.

Pred implementacijo preveriva dovoljenja in dostopnost vira. Najprej pripraviva testni vzorec in ponovljiv uvoz; ključe hraniva v lokalnem okolju oziroma GitHub Secrets. Mobilna aplikacija ne bo izvajala spletnega strganja.
